# 05 — AI-Assisted Production Workflow

*Systems for topic research, scripting, voiceovers, filming, editing, thumbnails, publishing, analytics review, and repurposing — with tools, templates, and a quality-control checklist.*

## 1. The pipeline, end to end

```
Topic Research → Script/Outline → Film/Record → Edit → Thumbnail →
Publish → Analytics Review → Repurpose (Shorts/TikTok/Reels)
```

Each stage below lists **what to do, an AI-assisted way to do it faster, and the output that feeds the next stage.**

## 2. Topic research

- **Input:** idea bank (file `02`), last week's analytics (file `07`), fan comments/requests.
- **Process:** each week, shortlist 3 candidate topics. For each, draft the title + thumbnail concept *before* committing (file `03`) — if you can't make those work, the topic isn't ready.
- **AI-assist:** use an LLM to generate 10 title variants and 5 hook variants per shortlisted topic, then pick using the checklist in file `03` rather than the AI's preference — AI is a variant generator here, not the decision-maker.
- **Output:** one chosen topic + title/thumbnail concept, added to the production calendar.

## 3. Scripting / outlining

- Use the script skeleton from file `03`, section 10, as the template every time.
- **Full script** for talking-head/tutorial sections (word-for-word, since precision matters for teaching content).
- **Beat outline only** for process/vlog footage (bullet points of what must be captured, not verbatim lines) — over-scripting reality content kills its authenticity.
- **AI-assist:** draft a first-pass script/outline from your bullet points, then rewrite every sentence in your own voice — an unedited AI script is instantly recognizable and undermines the "honest, unpolished" positioning from file `02`.
- **Output:** finalized script/outline + shot list (what footage is needed: A-roll talking head, B-roll of hands on gear, screen recording of DAW, etc.).

## 4. Voiceovers / audio

- Record scratch VO on a phone/USB mic while filming for pacing reference even if you'll re-record cleanly later.
- **AI-assist:** use AI transcription (auto-captions, or a dedicated transcription tool) immediately after recording — gives you a searchable text version of your footage for the edit and a caption-file starting point.
- Keep a simple audio checklist: no clipping, consistent levels across all A-roll takes, room tone recorded for 10 seconds per location (fixes edit-point audio gaps).

## 5. Filming

- **Minimum viable kit:** phone with a stabilizer/tripod, one directional mic (lavalier or shotgun), one key light (or window light). Budget gear is not a blocker for this channel's positioning — file `02` explicitly leans into "honest, small-scale."
- **Shot list discipline:** film all B-roll (studio, gear, hands, screen recordings) in a batch separate from A-roll talking segments — this is what makes batching in file `01`'s weekly schedule possible.
- **Capture 20-30% more footage than you think you need**, especially reaction/authentic moments — retention editing (file `03`) depends on having enough material for pattern interrupts.

## 6. Editing

- **Assembly pass:** cut to the script/outline order first, roughly, no polish.
- **Retention pass:** apply file `03`'s techniques explicitly — mark every 30-45 second mark and confirm there's a cut, cutaway, or visual change there.
- **Polish pass:** color, audio levels/ducking (music under dialogue), captions burned in for key lines (mobile-first, many viewers watch muted).
- **AI-assist:** AI-powered editing tools can auto-detect silences/filler words for a fast first cut, and auto-caption generation saves significant time — always human-review captions for accuracy, especially for music/technical terms an auto-captioner will mishear.
- **Tool categories to use** (pick based on budget, not brand loyalty): a non-linear editor (DaVinci Resolve is free and professional-grade — a strong default for a zero-to-low-budget channel), an AI transcription/caption tool, a simple thumbnail design tool.

## 7. Thumbnail creation

- Design thumbnail **before** finishing the edit, using the file `03` template — this keeps title/thumbnail/content aligned instead of thumbnail being an afterthought.
- Keep a reusable template file (consistent text placement, font, border/badge treatment) so each new thumbnail takes minutes, not an hour.
- **AI-assist:** AI image tools can generate background/composite elements (b-roll-style backdrops, stylized treatments) faster than manual compositing — but keep the focal subject (your actual face/gear/song) real, not AI-generated, to preserve authenticity.

## 8. Publishing checklist

Run file `04`, section 6's optimization checklist at this stage every time, plus:
- [ ] Correct category and relevant tags set
- [ ] End screen and cards added
- [ ] Pinned comment written
- [ ] Scheduled at the channel's tested optimal time (not always "publish immediately")
- [ ] Thumbnail double-checked at actual mobile size before going live

## 9. Analytics review

Handled fully in file `07` — the production workflow's job is simply to **feed clean data back into topic research** (section 2) every week, closing the loop.

## 10. Repurposing into Shorts, TikTok, Instagram Reels, and other platforms

- **Cut from long-form, don't produce separately.** Every long-form video should yield 3-5 short clips: the hook moment, the most surprising beat, the payoff, and any highly visual production moment.
- **Reformat, don't just crop:** vertical framing needs its own captions (large, high-contrast, burned in — most Shorts/Reels viewing is sound-off), and the first 1 second needs its own hook independent of the long-form video's hook (per file `04`, Shorts live and die in the first 1-3 seconds).
- **Platform-specific posting, same asset:** export once at 9:16, then publish natively to YouTube Shorts, TikTok, and Instagram Reels rather than only cross-posting via auto-share tools — native uploads generally get better initial distribution than detected re-posts/watermarked cross-posts.
- **AI-assist:** AI clipping tools can auto-detect high-energy or high-retention-likely moments in long-form footage to speed up the selection step — always manually confirm the clip still makes sense with zero context, since a good long-form moment doesn't always work standalone.
- **Feedback loop:** a Short that overperforms is strong evidence for a full long-form video on that exact topic — feed winners back into section 2's topic research.

## 11. Quality-control checklist (final gate before publishing anything)

- [ ] Does this serve the positioning statement from file `01`? (if not, stop and reconsider)
- [ ] Title + thumbnail pass the "stranger scrolling would stop" test
- [ ] First 3 seconds have a real hook, not an intro
- [ ] At least one pattern interrupt every 30-45 seconds
- [ ] Audio is clean: no clipping, no jarring level jumps, no dead air over ~1 second
- [ ] Captions present and accurate
- [ ] One clear CTA, placed after the payoff
- [ ] Nothing promised in title/thumbnail that the video doesn't deliver (protects long-term trust and retention data)
- [ ] Repurposing clips identified and cut before moving to the next project

## 12. Tool stack summary (budget-tiered)

| Stage | Free/cheap option | Paid upgrade path (once revenue starts, file `06`) |
|---|---|---|
| Editing | DaVinci Resolve (free) | Premiere Pro / Resolve Studio |
| Captions/transcription | YouTube auto-captions + manual fix | Dedicated AI captioning tool |
| Thumbnails | Free design tool with templates | Paid design tool / hire a designer at scale |
| Audio | Phone + budget lav mic | Dedicated audio interface + condenser mic |
| Scripting/ideation | Any general LLM assistant | Same, just more usage |
| Clipping for Shorts | Manual selection in editor | AI auto-clipping tool once volume justifies it |

Upgrade tools only when the current one is the actual bottleneck (measured by time spent or a QC checklist item failing repeatedly) — not preemptively. A better camera doesn't fix a weak hook.
